The PIP system, with a rose accent

Extracted from RecoverMe and PDF Reader: the same quiet neutral base, Hanken Grotesk with JetBrains Mono for counts, 10 · 14 · 20 · pill radii, 4-based spacing, Lucide at 1.75. PIP apps share everything except the one accent hue (blue, red). Love Stickers takes rose at the same lightness and chroma.

Components
Carried over: primary / secondary / ghost / destructive buttons, filter chips, segmented control, list rows, white cards, bottom nav with the raised Create (PDF Reader), empty state, dark toast, dialog, bottom sheet, honesty line.
New here: pack card with 6-thumb strip, tinted Add pill with progress fill, full-width Add bar with five states, sticker tile, theme tile.
Sticker art is a placeholder glyph per pack; real WebP previews stream from Cloud Storage. The phone-in-bubble glyph inside Add reads as WhatsApp while staying in our colours; swap in the official glyph at build if WhatsApp's brand terms allow.
